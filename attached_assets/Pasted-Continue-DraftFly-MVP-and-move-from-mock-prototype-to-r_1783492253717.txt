Build real backend integration structure:

1. Slack Integration
Create backend routes for:
- POST /api/slack/actions
- POST /api/slack/commands
- POST /api/slack/test-message

Requirements:
- Verify Slack signing secret.
- Read SLACK_BOT_TOKEN from environment variables.
- Send test approval message to configured Slack channel.
- Handle Send / Edit / Discard button payloads.
- Log all button actions.

2. Lemlist Integration
Create backend routes/services for:
- POST /api/webhooks/lemlist/reply
- GET /api/lemlist/campaigns
- POST /api/lemlist/send-reply

Requirements:
- Read LEMLIST_API_KEY from environment variables.
- Receive lead reply webhook.
- Extract leadId, campaignId, email/linkedin source, reply text, lead profile fields.
- Fetch or mock conversation history if API is not connected yet.
- Send approved reply back through Lemlist API when Send is confirmed.

3. Claude Integration
Create backend service:
- generateDraftReply()

Requirements:
- Read ANTHROPIC_API_KEY from environment variables.
- Generate reply based on:
  - campaign persona
  - reply rules
  - lead profile
  - region/nationality rules
  - conversation history
  - incoming reply
- Return draft, confidence score, detected intent and suggested next action.
